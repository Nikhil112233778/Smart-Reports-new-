# Smart Report

The Habit Smart Report as a page-by-page iPhone app (7 pages: about, score, results, compare, risks, reduce, plan).

## Folders

- `report/`: the report pages. `index.src.html` is the source: one HTML file with its styles, script and data.
  `build.py` builds `index.html` and `preview.html` from it.
- The app (repo root): an Expo app that shows the built report full screen in a web view. `src/reportHtml.ts` is
  generated by `scripts/sync_report.py`. Do not edit it by hand.

## Change the report and ship it

```bash
cd report && python3 build.py && cd ..   # build the pages
python3 scripts/sync_report.py           # pack them (with the Poppins fonts) into src/reportHtml.ts
npx eas-cli update --branch production --environment production --platform ios --message "..."   # live on phones
```

A new TestFlight build is needed only for native changes (icon, splash, packages):

```bash
npx eas-cli build --platform ios --profile production --non-interactive --auto-submit
```

To view the pages in a browser: `cd report && python3 -m http.server 8765`, then open http://127.0.0.1:8765/preview.html
